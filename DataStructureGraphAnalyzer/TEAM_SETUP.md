# Team GitHub Setup

Branches:
- feature/aashiqa-array-searching
- feature/shimla-stack-queue
- feature/thizan-linkedlist-performance
- feature/suaath-graph

Recommended workflow:
1. Each member works only on their feature branch.
2. Make meaningful commits.
3. Push the branch.
4. Open a Pull Request to main.
5. Aashiqa reviews and merges after testing.
6. Before final submission, all members should be able to explain their own code.
