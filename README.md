# Data Structure & Graph Performance Analyzer

## CIT300 Graded Practical Assignment 2

A Java console-based application demonstrating data structures, searching, graph traversal, and performance/complexity concepts.

## Main Features

- Array: Insert, Delete, Search, Display
- Stack: Push, Pop, Peek, Display
- Queue: Enqueue, Dequeue, Front, Display
- Linked List: Insert, Delete, Search, Display
- Linear Search
- Binary Search
- Graph: Add Vertex, Add Edge, Display
- BFS traversal
- DFS traversal
- Performance/complexity comparison
- Input validation and empty-structure handling

## How to Run

From the project root:

```bash
javac -d out src/*.java
java -cp out Main
```

Or open the project in VS Code and run `Main.java`.
